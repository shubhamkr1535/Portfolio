# Portfolio

A modern, fully responsive portfolio website built with HTML, CSS, and JavaScript. It showcases personal projects, resume information, and a contact form for professional networking.

## Live Demo

https://shubhamkr1535.github.io/Portfolio/

## Features

- Responsive layout for desktop, tablet, and mobile devices
- Professional portfolio landing page
- Project showcase section
- Resume and skills presentation
- Contact form and social/contact links
- Lightweight front-end implementation with no framework dependency

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/shubhamkr1535/Portfolio.git
```

2. Open the project folder:

```bash
cd Portfolio
```

3. Open `index.html` in a browser, or run a local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.

This project is configured for GitHub Pages and can be deployed directly from the repository using the default branch.
